Drowsiness Detection from HRV DataThis project aims to predict driver drowsiness levels by analyzing Heart Rate Variability (HRV) data. We utilize various data analysis techniques, feature engineering, and machine learning models to build and evaluate a predictive system.Project StatusThis project is actively in development. Key functionalities like data loading, feature engineering, and initial model training with Random Forest are implemented. See the Future Work section for our next steps.Project StructureHere is an overview of the key scripts in this repository:load_data.py: Loads the initial dataset and generates multiple exploratory data analysis (EDA) graphs, including histograms, box plots, and scatter plots to visualize the data distribution.feature_engineering.py: Processes the raw data to extract HRV features. It outputs a CSV file containing these HRV values, summarizing drowsiness metrics against them. This file is crucial for model training.data_split.py: Splits the engineered dataset into training, testing, and validation sets (70/30 split for train/test mentioned, validation split also included). This script ensures that the data is segregated equally to prevent model bias.train_model.py: Implements a Random Forest classifier to train on the HRV feature set. The current split is 70% for training and 30% for testing.train_model_llm.py: (EXPERIMENTAL) An exploratory script to fine-tune a Llama 3.1 8B parameter model for predicting KSS values. Note: This is not a primary component of the project, as Random Forest and XGBoost are proving to be more accurate and practical.Setup and InstallationFollow these steps to set up your local environment to run the project code.1.
